# P2c — Policy (bazaviy va dars qatlamlari, versiyalar, receipt'lar, managed extension) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Holat (2026-11-12):** Task 1–11 bajarildi. Chetlanishlar va xavfsizlik tekshiruvidan keyingi tuzatishlar [ADR 0015](../../adr/0015-policy.md)'da. **Kutilmoqda:** extension'ni do'konga chiqarish va qo'lda qabul sinovi.

**Goal:** IT admin bazaviy siyosatni, o'qituvchi esa dars web siyosatini versiyalab beradi. Helper va Companion uni qo'llaydi, har qoida natijasini receipt qiladi va panelda desired/applied ko'rinadi. Chrome/Edge'dagi NetSchool extension web qoidalarini majburlaydi.

**Architecture:**
- Hub siyosatni immutable versiyalar sifatida saqlaydi (`policy_versions`), joriy ko'rsatkichni `policy_assignments`da, qurilma natijasini `policy_receipts`da (qurilma × qatlam × xabar beruvchi) tutadi. Qatlamlarni birlashtirish va URL pattern mantig'i `packages/domain/src/policy/`da sof funksiyalar: hub, Companion va extension bir xil koddan foydalanadi.
- Helper (SYSTEM) bazaviy siyosatni o'z kaliti bilan oladi, keshlaydi, Chrome/Edge HKLM siyosatlarini yozadi va 60 s'da drift'ni tuzatadi.
- Companion ikkala qatlamni oladi va o'quvchi sessiyasida named pipe orqali web qoidalarini beradi. Chrome/Edge'ning native messaging host'i (`netschool-helper.exe native-host`) shu pipe'ni extension'ga ulaydi. Extension (MV3) `declarativeNetRequest` dinamik qoidalarini qo'llab, natijani qaytaradi.

**Tech Stack:** NestJS + Drizzle (PGlite/PostgreSQL), zod contracts, React (apps/web), Electron/Node (Companion, `node:net` named pipe), Go 1.26 + `golang.org/x/sys` (Helper), Chrome MV3 extension (TypeScript, esbuild).

**Spec:** [docs/superpowers/specs/2026-11-12-p2c-policy-design.md](../specs/2026-11-12-p2c-policy-design.md). Spec §7.1, §8, §9, §10; [ADR 0014](../../adr/0014-windows-helper.md).

## Global Constraints

- Ikki qatlam: `baseline` (tashkilot va site darajasi, doimiy, oflayn saqlanadi) va `lesson` (faqat faol dars, lease 120 s, yangilash har 30 s, monotonic, rebootda qayta qo'llanmaydi). Lesson web siyosati overlay qulfidan **mustaqil**: qurilma faol dars a'zosi bo'lsa amalda.
- Birlashtirish: qattiqrog'i yutadi. Site va o'qituvchi yuqori qatlam cheklovini bo'shata olmaydi; bazaviy bloklangan sayt dars allowlist'ida ham bloklanadi.
- `policy_versions` immutable: UPDATE/DELETE DB triggeri bilan rad etiladi. Rollback eski mazmundan yangi versiya yaratadi.
- Har yozuvda `organization_id`, kerak joyda `site_id` (CLAUDE.md).
- Ruxsatlar: bazaviy siyosat — `school_admin` (tashkilot va istalgan site), `it_support` (faqat o'z site'i). Lesson policy — dars egasi o'qituvchi va site admin. `student` — hech narsa. Rad etish auditda.
- Qurilma yo'llari: Companion — `GET /api/v1/device/policy`, `PUT /api/v1/device/policy/receipt` (qurilma kaliti). Helper — `GET /api/v1/device/helper/policy`, `PUT /api/v1/device/helper/policy/receipt` (helper kaliti, `x-ns-signer: helper`). ADR 0014 chegarasi bo'shatilmaydi.
- Siyosat hujjatida erkin skript/buyruq/regex yo'q; faqat tiplangan maydonlar (`strictObject`). URL pattern: `host` yoki `*.host`, ixtiyoriy `/yo'l-prefiksi`; har ro'yxatda ≤ 500 pattern, har pattern ≤ 300 belgi.
- Qo'llab-quvvatlanadigan brauzerlar: Google Chrome va Microsoft Edge. Boshqalari faqat `unmanaged_browser` sifatida aniqlanadi.
- Extension do'konlarga unlisted chiqariladi; ID'lar hub konfiguratsiyasida (`NETSCHOOL_EXTENSION_ID_CHROME`, `NETSCHOOL_EXTENSION_ID_EDGE`), kodda qattiq yozilmaydi. ID yo'q bo'lsa `browser.managed` → `failed`, kod `extension_unpublished`. Repoda va hub'da extension imzolash kaliti yo'q.
- TLS fail-closed, `rejectUnauthorized: false`/`InsecureSkipVerify` yo'q. Capability matrix'da dalilsiz `passed` yo'q; qabul sinovi standart foydalanuvchi akkauntida.
- Hujjatlar va izohlar o'zbekcha, commit xabarlari inglizcha conventional commits.

### Task 1: Domain — URL pattern va qatlamlarni birlashtirish

**Files:**

- Modify: `packages/domain/src/index.ts` (eksport)

**Interfaces:**
- Produces:
  - `type UrlPattern = string` (normallashgan). `normalizePattern(input: string): UrlPattern | null` — kichik harf, IDN → punycode (`new URL('http://' + host).hostname`), oxirgi nuqta olib tashlanadi, `http(s)://` prefiksi va port olib tashlanadi, `*.` faqat boshida, yo'l prefiksi `/` bilan boshlanadi; regex belgilari, bo'sh joy, boshqa sxema → `null`. Uzunlik ≤ 300.
  - `matchesUrl(pattern: UrlPattern, url: URL): boolean` — host teng yoki (`*.x` uchun) `x` yoki `.x` bilan tugaydi, yo'l prefiksi mos.
  - `interface BaselineDocument { schemaVersion: 1; web?: { blocked: UrlPattern[] }; browser?: { managed?: boolean; incognito?: 'allowed' | 'disabled'; devTools?: 'allowed' | 'disabled' }; os?: { standardUser?: boolean; blockAppInstall?: boolean; lockWallpaper?: boolean } }`.
  - `interface EffectiveBaseline { web: { blocked: UrlPattern[] }; browser: { managed: boolean; incognito: 'allowed' | 'disabled'; devTools: 'allowed' | 'disabled' }; os: { standardUser: boolean; blockAppInstall: boolean; lockWallpaper: boolean } }`.
  - `interface LessonDocument { schemaVersion: 1; web: { mode: 'off' | 'allowlist' | 'blocklist'; patterns: UrlPattern[] } }`.
  - `mergeBaseline(org: BaselineDocument | null, site: BaselineDocument | null): EffectiveBaseline` — standartlar: bo'sh ro'yxat, `false`, `'allowed'`; ro'yxatlar birlashadi (takrorsiz, saralangan), `true`/`'disabled'` yutadi.
  - `effectiveWeb(baseline: EffectiveBaseline, lesson: LessonDocument | null): { block: UrlPattern[]; allowOnly: UrlPattern[] | null }` — `allowOnly` null bo'lmasa faqat shular ruxsat, lekin `block` doim ustun.
  - `type RuleKey = 'web.blocked' | 'web.lesson' | 'browser.managed' | 'browser.incognito' | 'browser.devTools' | 'browser.onlyManaged' | 'os.standardUser' | 'os.blockAppInstall' | 'os.lockWallpaper'`.
  - `activeRules(layer: 'baseline' | 'lesson', doc: EffectiveBaseline | LessonDocument, reporter: 'companion' | 'helper'): RuleKey[]` — har xabar beruvchi qaysi faol qoidalar uchun javob berishi: Companion — `web.blocked` (ro'yxat bo'sh bo'lmasa), `web.lesson` (mode ≠ off); Helper — `browser.*` (managed bo'lsa uchalasi + `browser.onlyManaged`; incognito/devTools faqat `disabled` bo'lsa), `os.*` (`true` bo'lsa).
  - `receiptStatus(expected: RuleKey[], rules: Partial<Record<RuleKey, { state: 'applied' | 'failed' | 'unsupported' }>>): 'applied' | 'partial' | 'failed'` — hammasi applied → applied; birortasi ham applied emas va expected bo'sh emas → failed; aks holda partial. Bo'sh `expected` → applied.
