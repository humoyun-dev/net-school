# P2d0 — Kuchli bloklash (Windows) Implementation Plan

> **Holat: reja (kod yozilmagan).** Birinchi vazifa (spike) natijasiga qarab qolgan vazifalar o'zgarishi mumkin.

**Goal:** Dars paytida bloklangan o'quvchi Windows'da overlay'dan chiqib keta olmaydi: Win, Alt+Tab, Ctrl+Esc, Ctrl+Shift+Esc, Alt+F4 klaviatura hook bilan to'siladi; Ctrl+Alt+Del ekranidagi Vazifalar menejeri, Qulflash, Parol o'zgartirish va Chiqish bandlari va Win+L siyosat bilan o'chiriladi. Bloklash tugashi bilan (unlock, lease tugashi, dars tugashi, Companion qayta ishga tushishi) hammasi qaytariladi.

**Asos:** [ADR 0012](../../adr/0012-windows-poc-results.md) 2-qaror, [risks.md](../../poc/risks.md) #12, P0c sinovi: Win, Ctrl+Shift+Esc va Ctrl+Alt+Del soft overlay'dan o'tdi (Alt+Tab, Win+D to'sildi).

## Cheklovlar va qarorlar

- **Faqat Windows x64.** macOS/Linux'da `classroom.overlay` soft bo'lib qoladi (ADR 0007: sinalmagan OS uchun da'vo yo'q).
- **Laboratoriyalarda Windows Home ham bor** → Keyboard Filter, Assigned Access, Group Policy muharriri ishlatilmaydi.
- **Hook foydalanuvchi sessiyasida.** `WH_KEYBOARD_LL` Ctrl+Alt+Del (SAS) va Win+L'ni ushlay olmaydi. Ular faqat siyosat bilan to'siladi.
- **Hook kodi native.** Electron main'ida FFI (`koffi`) bilan chaqiriladi; kelajakdagi Go helper (P2d) shu vazifani olganda almashtiriladi. Tanlov spike (T1) natijasi bilan tasdiqlanadi; ishlamasa muqobil: kichik mustaqil `.exe` (hook'ni o'zi ushlaydi, Companion bilan stdin/stdout orqali gaplashadi).
- **Hook callback tez bo'lishi shart.** Windows `LowLevelHooksTimeout` dan oshgan hook'ni jimgina o'chiradi. Callback faqat toza predicate chaqiradi; I/O va log yo'q.
- **Siyosat HKCU orqali** (`Software\Microsoft\Windows\CurrentVersion\Policies\{System,Explorer}`), `reg.exe` bilan (native kerak emas). **Cheklov:** Companion o'quvchi huquqida ishlaydi, shuning uchun o'quvchi bu qiymatlarni o'zi ham o'zgartira oladi. Bu to'liq himoya emas, SYSTEM helper (P2d) bu bo'shliqni yopadi. Matrix'da `classroom.overlay` shu sababli `partial` qolishi mumkin; to'liq `passed` faqat P2d'dan keyin.
- **Fail-safe:** Companion bloklash paytida o'lib qolsa, siyosat o'chmay qoladi (Vazifalar menejeri yo'q). Shuning uchun har ishga tushishda siyosat jurnali tekshiriladi va bloklash faol bo'lmasa hammasi qaytariladi. Companion umuman qaytmasa, keyingi kirishdagi HKLM Run (`enroll.cmd`) uni ishga tushiradi.
- Hook yoki siyosat o'rnatilmasa, capability sababi bilan `partial` bo'ladi va panel buni «Yumshoq» deb ko'rsatadi. Yolg'on «Qattiq» da'vo yo'q.

## File Structure

- `apps/companion/src/core/key-policy.ts` — toza predicate: `shouldBlock(vkCode, flags, modifierState) → boolean`; Electron/native'siz.
- `apps/companion/src/core/lock-policy.ts` — HKCU siyosat jadvali, `apply()`, `restore()`, jurnal (oldingi qiymatlar) `StateCache`da.
- `apps/companion/src/main/win-keyboard-hook.ts` — `koffi` bilan `SetWindowsHookExW(WH_KEYBOARD_LL)`, `install()/uninstall()`, holat.
- `apps/companion/src/main/hard-lock.ts` — overlay holatiga bog'lanadi: locked → hook + siyosat; unlocked → qaytarish.
- `apps/companion/src/core/capabilities.ts` — `classroom.overlay` darajasi (`soft` | `hard`) va sabab.
- `apps/companion/src/core/i18n.ts` — overlay matni: «Yumshoq bloklash» ↔ «Bloklangan».
- `docs/poc/capability-matrix.md`, `docs/poc/risks.md`, yangi ADR 0013.

## Tasks

### T1 — Spike: hook Electron 45 ichida ishlaydimi
- [ ] `koffi` ni `apps/companion`ga qo'shish, `pack-win` yig'ishida `.node` binary'si paketga kirishini tekshirish (asar tashqarisida).
- [ ] Minimal skript: main jarayonda `WH_KEYBOARD_LL` o'rnatish, `Win`, `Ctrl+Shift+Esc` ni `1` qaytarib yutish, boshqa tugmalarni `CallNextHookEx` ga o'tkazish.
- [ ] Windows mashinada qo'lda tekshirish: Win, Ctrl+Esc, Ctrl+Shift+Esc, Alt+Tab, Alt+F4 yutiladi; oddiy yozuv ishlaydi; callback 1 ms ichida.
- [ ] Natija: ishlasa T2–T6 davom; ishlamasa muqobil `.exe` varianti rejaga qo'shiladi va foydalanuvchi bilan kelishiladi.

### T2 — `key-policy.ts` (toza predicate)
- [ ] `vkCode` + modifier holati bo'yicha to'siladigan to'plam: `VK_LWIN`, `VK_RWIN`, `Alt+Tab`, `Alt+Esc`, `Ctrl+Esc`, `Ctrl+Shift+Esc`, `Alt+F4`, `Alt+Space`.
- [ ] Injected hodisalar (`LLKHF_INJECTED`) to'silmaydi: MeshAgent orqali o'qituvchining masofaviy boshqaruvi ishlashi kerak.
- [ ] Vitest: jadval bo'yicha testlar; oddiy harf, raqam, Shift+harf, Ctrl+C to'silmaydi.

### T3 — `lock-policy.ts` (siyosat va jurnal)
- [ ] Qiymatlar: `DisableTaskMgr`, `DisableLockWorkstation`, `DisableChangePassword` (`Policies\System`), `NoLogoff`, `NoWinKeys` (`Policies\Explorer`).
- [ ] `apply()` avval oldingi qiymatni (yo'q/son) jurnalga yozadi, keyin o'rnatadi; `restore()` jurnal bo'yicha qaytaradi va jurnalni tozalaydi.
- [ ] `reg.exe` `execFile` bilan, argumentlar qat'iy ro'yxatdan (foydalanuvchi matni yo'q).
- [ ] `reconcile(lockActive)`: ishga tushishda jurnal bo'sh emas va bloklash faol emas → `restore()`.
- [ ] Vitest: `reg` chaqiruvi in'ektsiya qilingan soxta ijrochi bilan; apply→restore, qisman xato, qayta ishga tushish.

### T4 — `win-keyboard-hook.ts` va `hard-lock.ts`
- [ ] `install()` idempotent; `uninstall()` hook tutqichini bo'shatadi; o'rnatish xatosi → holat `failed` + sabab.
- [ ] `hard-lock` `OverlayController` o'zgarishlariga ulanadi (`onChange`): locked → `apply()` + `install()`; unlocked/lease tugashi → ikkalasi qaytariladi.
- [ ] `before-quit` va `uncaughtException`'da `uninstall()` + `restore()`.
- [ ] Windows bo'lmasa modul hech narsa qilmaydi (`platform` tekshiruvi).

### T5 — Capability va interfeys
- [ ] `classroom.overlay`: hook va siyosat ikkalasi ham faol bo'lsa `hard`; biri bo'lmasa `soft` + sabab (`hook_failed`, `policy_failed`, `unsupported_os`).
- [ ] Hub contract'ida shu qiymat o'tadimi tekshirish (`packages/contracts`); o'zgarish kerak bo'lsa schema versiyasi.
- [ ] Overlay matni darajaga qarab: «Yumshoq bloklash» yoki «Bloklangan» (uz/ru/en).
- [ ] Ochiq kamchilik bilan birga: reboot'dan keyin qayta qo'llangan bloklashda o'qituvchi matni yo'qolishi (risk #15), heartbeat overlay holatiga matnni qo'shish.

### T6 — Sinov va hujjat
- [ ] Windows x64 qo'lda sinov: Win, Win+L, Ctrl+Esc, Ctrl+Shift+Esc, Ctrl+Alt+Del bandlari, Alt+Tab, Alt+F4; unlock'dan keyin hammasi qaytadi; Companion'ni majburan o'ldirib qayta ishga tushirish → siyosat qaytadi; hub o'chsa lease tugab hammasi qaytadi.
- [ ] Masofaviy boshqaruv (o'qituvchi ko'rishi/boshqarishi) bloklash paytida ham ishlaydi.
- [ ] `capability-matrix.md` va `risks.md` (#4, #12) yangilanadi; ADR 0013.
- [ ] Natija `docs/poc/results/windows-x64-<sana>-hard-lock.md` ga.

## Qabul mezonlari
1. Bloklash faol: Win, Alt+Tab, Ctrl+Esc, Ctrl+Shift+Esc, Alt+F4 ishlamaydi; Ctrl+Alt+Del ekranida Vazifalar menejeri, Qulflash, Parol o'zgartirish, Chiqish bandlari yo'q; Win+L ishlamaydi.
2. Unlock, lease tugashi, dars tugashi va Companion qayta ishga tushishi hammasini qaytaradi; qaytarilmay qolgan siyosat qolmaydi.
3. O'qituvchining masofaviy kiritishi to'silmaydi.
4. Hook yoki siyosat o'rnatilmasa capability `soft` + sabab, interfeys «Yumshoq».
5. Cheklov hujjatlashtirilgan: o'quvchi HKCU qiymatlarini o'zi o'zgartira oladi; to'liq himoya P2d helper bilan.

## Bu rejaga kirmaydi
SYSTEM helper va Companion'ni o'ldirib bo'lmaydigan qilish (P2d), standart foydalanuvchi va dastur o'rnatish taqiqi (P2h), macOS/Linux, Windows ARM64.
